# Sıra screenshots

Add portrait App screenshots to this directory as `.png`, `.jpg`, `.jpeg`,
`.webp`, or `.avif` files. The app page discovers them automatically at build
time.

Prefix filenames with two digits to control gallery order, and make the rest of
each filename describe the screen; it becomes the visible caption and accessible
image description. For example:

- `01-new-game.png`
- `02-running-score.png`
- `03-game-summary.png`
